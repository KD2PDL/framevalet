{{ setting_row('backup_interval', 'Automatic backup every (hours, 0 = off)', 'number', none) }} {{ setting_row('backup_remote', 'Copy backups to rclone remote', 'text', 'onedrive:FrameValet Backups') }} {{ setting_row('backup_passphrase', 'Encrypt archives with passphrase', 'text', 'recommended before copying off-box') }} {{ setting_row('backup_ping_url', 'Health ping URL (Uptime Kuma push)', 'text', 'https://status.example.com/api/push/abc123') }}

A backup holds the database (users, settings, API keys, tunnel token, library metadata), TV pairing tokens, and branding. The last 7 are kept locally. With an rclone remote set, each scheduled backup is copied to <remote>/archives and originals/ is synced to <remote>/originals, so a full rebuild is the archive plus that folder. A passphrase encrypts the archive (AES-256-GCM) since it contains secrets; keep the passphrase somewhere else, it is needed to restore. The ping URL is called after every scheduled backup, with status=down on failure, so a monitor can alert when backups stop.

Restore

To move to a new machine: install framevalet there, update it to at least the version that made the backup, copy originals/ into its data directory, then restore here. Encrypted archives use the saved passphrase unless you enter one.
